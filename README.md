# PWM呼吸灯 + OLED实时显示亮度

## 原版是什么
教程里的PWM呼吸灯例程。LED一亮一暗，肉眼看个大概，但完全不知道当前占空比是多少。

## 我为什么要改
灯在呼吸，但数据是黑的。我不知道我写的`PWM_SetCompare1(i)`到底有没有按我设的值在变。调试的时候没法验证，只能靠猜。

## 我改了什么
- 加了一块OLED屏，实时显示当前亮度值
- 用`if(brightness != LastNum)`判断数据变了才刷新屏幕，避免无脑刷屏占资源
- 修了一个bug：原作者第二个for循环写成了死循环，我改成了`for(i=100; i>0; i--)`

## 改完的效果
LED亮到哪，屏幕上数字就跟到哪。调试的时候一眼就能看到PWM占空比在变化，不再是黑盒操作。

## 学到了什么
硬件调试不能靠猜，得想办法把内部状态可视化。这个思路后来在我做双51分拣系统的时候也用上了——用数码管实时显示计数，才知道程序跑到哪一步了。


# 定时器中断 + 按键手动控制计数

## 原版是什么
教程里的定时器中断例程。定时器每隔一段时间触发一次中断，`Num`变量无脑自增，OLED屏幕疯狂刷新。

## 我为什么要改
原版跑起来，数字跳得飞快，我看都来不及看。而且我不知道它什么时候会变，整个节奏完全被程序控制，我没法介入。我就想：能不能让程序听我的，而不是我追着程序跑？

## 我改了什么
- 加了一个按键，只有按下特定按键（键码2）时，`Num`才自增一次
- 主循环里加了`if(Num != LastNum)`，只在数据变化时才刷新OLED，不用白占资源
- 按一次，加一次，显示一次。节奏完全由我来控制

## 改完的效果
数字变化由我手指说了算。调试的时候可以慢慢按、慢慢看，不会像原版那样眼花缭乱。

## 学到了什么
程序不是跑起来就行，得考虑使用者怎么跟它交互。之前做分拣系统的时候，我也专门加了一个按键让“工人”能控制启动和停止——这个意识就是从这里开始有的。
